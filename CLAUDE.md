# Proyecto: web-petflow

## De qué se trata
Página web de **PetFlow Arg** (tienda online argentina de accesorios y
juguetes para perros). El objetivo principal es **practicar HTML, CSS
y JavaScript** mientras armo algo útil para el emprendimiento.

Es un proyecto **separado** del bot de WhatsApp (`bot-whatsapp`). No se
mezclan.

## Tipo de página
**Landing page de una sola página (one-page)** con varias secciones
navegables desde un menú superior:
- Inicio (hero / portada)
- Productos
- Sobre PetFlow Arg
- Contacto (con formulario validado en JS)

## Stack
- **HTML5** plano.
- **CSS3** plano (sin frameworks tipo Bootstrap o Tailwind al arranque).
- **JavaScript vanilla** (sin React, sin Vue, sin nada).
- Sin servidor: se abre con doble clic en `index.html`.

## Estructura de archivos prevista
- `index.html` — estructura de la página.
- `styles.css` — todos los estilos.
- `script.js` — toda la interacción JavaScript.
- `img/` — carpeta para imágenes (cuando hagan falta).

## Sobre PetFlow Arg (para el contenido de la web)
- **Rubro:** Tienda online de accesorios y juguetes para perros (Argentina).
- **Categorías de productos:** Accesorios (collares, correas, camas) y
  juguetes / entretenimiento.
- **Envíos:** Toda Argentina (Andreani / Correo + cadetería local).
- **Retiro:** También se puede retirar en punto físico.
- **Formas de pago:** Efectivo, tarjeta, MercadoPago, transferencia
  (con descuento por transferencia).
- **Atención humana:** Lunes a sábado, horario comercial.
- **Tono:** Cercano y cálido, tratamiento de "vos", uso moderado de
  emojis.

## Cosas que NO quiero
- No uses emojis dentro del código.
- No agregues tracking ni analytics.
- No uses frameworks de CSS (Bootstrap, Tailwind) al arranque.
- No uses frameworks de JS (React, Vue, etc.) al arranque.
